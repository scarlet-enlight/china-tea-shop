# China Tea Shop

Full-stack web app built as a university team project 
to learn CI/CD and containerization fundamentals.

## Team
3 people — DevOps, Backend, Frontend roles.
LonelyLake role: DevOps (containerization, CI/CD pipeline)

## Stack
- Backend: Flask, SQLAlchemy, SQLite
- Frontend: React, Nginx
- DevOps: Docker, Docker Compose, Jenkins

## What's here
- Containerized backend and frontend with Docker Compose
- Jenkins pipeline: automated build, test, push to Docker Hub
- Backend tests with pytest

## Quick Start
docker compose up --build
- Backend: http://localhost:5000
- Frontend: http://localhost:3000
